# TP Web — Travail pratique JavaScript

**Auteur :** Guilherm CADRAN (23101509)

## Description
Ce dépôt contient le travail pratique réalisé en JavaScript pour le cours de We. Le projet met en œuvre des interactions sur un canevas (`canvas`) : dessin de formes, gestion du drag & drop, modification des couleurs et autres interactions utilisateur.

## Difficultés rencontrées
- **`bind(this)` :** compréhension et usage de `bind(this)` qui a posé problème au début.
- **Expérience JS limitée :** n'ayant pas beaucoup pratiqué JavaScript, je me suis appuyé sur les vidéos du cours pour finaliser le TP.
- **Gestion des couleurs :** quelques difficultés sur la logique et l'application des couleurs.
- **Coordonnées souris / DnD :** confusion entre les coordonnées (x, y) de la souris et celles utilisées pour le drag & drop ; cela a nécessité beaucoup de débogage avec des `console.log()`.
- **Erreurs de typage :** pendant le TP, il m'est arrivé d'avoir plusieurs erreurs de typage classiques, évitables facilement avec TypeScript.


## Ajouts et améliorations
- **`clearShapes()` :** ajout d'un bouton qui réinitialise la liste des rectangles et des lignes.


## Lancer le TP
Ouvrir `index.html` (ou `canvas.html`) dans un navigateur moderne (Chrome, Firefox). L'interface permet d'interagir directement avec le canevas et d'utiliser les fonctionnalités implémentées.
